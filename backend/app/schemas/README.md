# Pydantic Schemas Directory (`app/schemas/`)

This directory will contain Pydantic schemas for request validation and response serialization.

## Planned Schemas:
- `user.py`: `UserCreate`, `UserRead`, `UserUpdate`
- `skill.py`: `SkillRead`, `SkillCreate`
- `swap.py`: `SwapRequestCreate`, `SwapRequestRead`
- `recommendation.py`: `MatchScoreResponse`, `MatchReasonRead`
