# Business Services Directory (`app/services/`)

This directory will encapsulate business logic, third-party integrations, and algorithm engines.

## Planned Modules:
- `recommendation.py`: Scikit-learn powered recommendation algorithm (content-based filtering, cosine similarity, 2-way skill matching matrix, collaborative filtering)
- `matching.py`: Reciprocal match score computation and reasoning generator
- `auth.py`: JWT token creation, password hashing, and authorization checks
