# Database Models Directory (`app/models/`)

This directory will contain SQLAlchemy ORM database models for SkillSwap AI.

## Planned Schemas for Future Stages:
- `user.py`: Student profile details (name, email, university, major, year, bio, rating)
- `skill.py`: Catalog of teachable and requested skills
- `user_skill.py`: Join table mapping offered vs. wanted skills with proficiency level
- `swap_request.py`: Skill swap proposals between students
- `review.py`: Rating & feedback given after completing a swap session
